## Changes since 1.0.52

### Fixes
- **Optimization / HUD Caching on 1.21.11:** with Fabric API 0.141 or newer, turning on HUD Caching hid the whole AIO PvP HUD, together with HUD elements of other mods (for example the Xaero's Minimap frame). They are drawn into the cached HUD again.

### Other
- README: the compatibility list now covers all four Minecraft versions, with the mods that have no 26.x version yet and the problems found in other mods (Ok Zoomer on Java 21, Perspektive 1.4.8 on 26.2, Iris with Sodium 0.9.3 on 26.3). Replay Mod is now tested too.
- The four release jars are now built by GitHub Actions.
