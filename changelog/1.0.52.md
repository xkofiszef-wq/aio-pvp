## Changes since 1.0.51

### New
- **Optimization / HUD Caching on 26.x:** HUD Caching is now available on Minecraft 26.1.2, 26.2 and 26.3 too. The HUD is drawn into a texture at most 20 times per second and the other frames only show that texture; markers and party heads still update every frame.
- **Party:** heads of far party members (known only from shared coordinates) now move smoothly. The mod estimates the movement from the last two position updates and glides the head there, instead of jumping on every update.

### Changes
- **Beta labels:** Party (with Party Vote) and Animate Only Visible Textures are now marked "(beta)" in the menu.
- **Optimization / Animate Only Visible Textures on 26.x:** the animated textures of each chunk section are now read from the block models, like on 1.21.11 since 1.0.51. This works no matter how Fabric API or other mods draw blocks.
- **Party Vote settings:** look settings saved by older versions in the old Party Vote module (background, Yes/No colors, rounding) are moved to the Party module automatically, so nothing resets after the update.

### Other
- README: up-to-date feature list, a Performance section with measured FPS, and a Beta features section.
- GitHub Actions now builds all four versions on every push.
